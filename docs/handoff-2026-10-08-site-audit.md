carry on without re-reading the day. Everything below is in the repo or in TimeAssembler.

## Where things stand

- Live at https://agizeitgeist.com, deployed by the GitHub workflow on every push to main
  (`.github/workflows/deploy.yml`; secrets set 2026-10-08). Do not deploy by hand with
  wrangler as well: a hand deploy racing the workflow briefly served a stale page tonight.
- The page is generated by `scripts/site.py` from `data/*.csv` and
  `docs/singularity-entry-thresholds.json`. Charts: `scripts/charts.py` (the named-experts
  chart), `scripts/vanguard_figure.py` (the r/singularity chart), and the four condition
  charts inside `site.py`. `scripts/validate.py` must pass before any commit.
- Design: the Sentient Horizons design standard (`sentient-horizons/design/README.md`),
  shared stylesheet `site/deep-field.css` (version 1.2.0, copied unchanged), the page shell
  and footer in `site.py`. The hero's type roles follow The Belt Equation: sans for the
  answer and claims, mono with tabular figures for numbers, serif only for prose.
- **The public-writing rule (John, 2026-10-08; standard section 1a):** no internal project
  language on any public page; build every idea from scratch for a reader who knows only
  what a five-year-old knows plus what the page has already said; audit top to bottom.
  The working documents under `/docs/` are published as written, each with a preface.
